# 微信小程序服务器域名配置指南

## 问题说明

如果在小程序开发者工具中可以正常使用，但用手机扫码进入小程序时提示"网络请求失败"，通常是因为**小程序服务器域名白名单未配置**。

微信小程序在真机上会强制检查服务器域名白名单，即使代码中设置了 `urlCheck: false` 也无法绕过。

## 配置步骤

### 1. 登录微信公众平台

访问 [微信公众平台](https://mp.weixin.qq.com/)，使用小程序管理员账号登录。

### 2. 进入开发设置

1. 点击左侧菜单 **"开发"** → **"开发管理"**
2. 点击 **"开发设置"** 标签页
3. 找到 **"服务器域名"** 配置区域

### 3. 配置服务器域名

在 **"request合法域名"** 中添加以下域名：

```
https://hvoqpnuvbtfp.sealosbja.site
```

**注意**：
- 域名必须使用 `https://` 协议
- 不要包含路径，只填写域名部分
- 不要包含端口号

### 4. 配置其他域名（如需要）

如果使用了文件上传/下载功能，还需要配置：

**uploadFile合法域名**：
```
https://hvoqpnuvbtfp.sealosbja.site
```

**downloadFile合法域名**：
```
https://hvoqpnuvbtfp.sealosbja.site
```

### 5. 保存配置

点击 **"保存"** 按钮，配置会立即生效。

### 6. 重新编译和测试

1. 在微信开发者工具中重新编译小程序
2. 使用手机扫码测试，确认网络请求正常

## 常见问题

### Q1: 配置后仍然提示网络请求失败？

**A**: 请检查：
1. 域名是否正确（注意不要有多余的空格或斜杠）
2. 是否使用了 `https://` 协议
3. 是否点击了"保存"按钮
4. 是否重新编译了小程序

### Q2: 开发环境可以使用，但真机不行？

**A**: 这是正常现象。开发者工具默认不检查域名白名单，但真机会强制检查。必须在微信公众平台配置服务器域名。

### Q3: 如何验证域名配置是否生效？

**A**: 
1. 在微信公众平台的"开发设置"中查看已配置的域名列表
2. 使用手机扫码进入小程序，尝试登录或调用API
3. 如果仍然失败，查看小程序控制台的错误信息

### Q4: 域名配置有数量限制吗？

**A**: 是的，每个类型（request、uploadFile、downloadFile）最多可以配置 20 个域名。
